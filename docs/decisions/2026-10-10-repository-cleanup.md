# 未使用入口と旧文書の整理

Status: accepted

現行仕様と、過去の提案・移行手順・実験成績を同じ入口から読むことで、廃止済みのV1/PCAフォールバックや旧CLIを現在の契約と誤認する余地があった。

- 現行文書の入口を `docs/README.md` にまとめ、旧CLIガイド・モデル要約・運用方針案・設計案・参考資料を `archive/docs/` へ本文を変えず移す。研究スクリプトの設計参照と現行文書のリンクを更新する。
- 旧運用方針案を現行運用・技術仕様の規約として扱わず、共通の不変条件はAGENTS.mdへ参照する。履歴の監査結論・成績・Phase状態から現行の受入を推測しない。
- 用途を終え、現在のコード・設定・テスト・バッチから呼ばれていない `scripts/migrate_production_config.py` を削除する。現在の読込処理が使う設定正規化APIは維持する。
- df_execの日付範囲確認は `scripts/check_df_exec_range.py` を残し、研究実験ディレクトリ内の重複入口を削除する。
- 無効化済み旧ネスト設定は `configs/archive/` に本文を変えず保存し、履歴の重複したPhase 32記載を1件にする。

本番計算・監査・フォールバック・発注経路と有効設定は変更しない。研究の再現コード、過去レポート、実験registry、運用データは保持する。静的参照がないことだけで本番モジュールや研究実験を削除しない。

移設一覧・削除根拠・検証範囲は [整理報告](../../reports/20261010_repository_cleanup/report.md) に記録する。
