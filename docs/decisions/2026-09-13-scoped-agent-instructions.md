# 作業範囲に応じた AGENTS.md / Skill の参照

- Date: 2026-09-13
- Status: accepted

## 背景

OpenAI の [Rethinking skills and prompts for GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra) を参考に、Skill の適用条件、常時参照する文書、作業を止める条件を見直した。この記事が提案する、短い description、必要時だけの詳細参照、依頼の完了条件に合わせた指示を、このリポジトリの運用規約へ適用する。

直前の改訂で9個の Skill は短く整理されていた。一方、追加された `debugging` には、旧パス・存在しない Skill・固定の稼働時刻や閾値・運用バッチの再実行を促す手順が残り、AGENTS.md の共通規約と食い違っていた。

## 決定

- AGENTS.md は共通規約と不変条件の正本を保つ。設計文書は対象の構造・数理・設計判断に応じて参照し、ロードマップ照合はリファクタリングや Phase の進捗を扱う場合に適用する。
- Skill の description は実際の作業に絞る。短い Skill に一律の参照層を追加せず、複数の診断を持つ `debugging` だけ症状別の3文書へ詳細を分ける。
- 修正依頼の完了は、範囲内の実装・必要な検証・文書更新までとする。調査のみの依頼、本番操作の権限、実験採用と本番昇格の区別は維持する。
- データ整合、8つの不変条件、実験評価規約は維持する。実行コード・挙動に関わる設定変更後の全テストは、このリポジトリの検証要件として残す。文書のみの変更は文書を検証する。

## 検証と限界

改訂対象、現行コードとの照合結果、形式・参照・依頼例の検証は [作業レポート](../../reports/20260913_agent_instructions/report.md) に記録する。モデル設定・本番コード・本番設定の変更は伴わず、指示の整理だけでモデルの性能向上や全 Phase の完了を保証しない。
