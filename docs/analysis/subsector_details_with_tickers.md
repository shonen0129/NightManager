# サブセクター詳細：銘柄構成と感応度ラベル

各サブセクターの銘柄構成と感応度ラベルの詳細

## 感応度ラベルの意味

- **w3 (成長感応度)**: 経済成長に対する感応度（プラス＝成長株、マイナス＝守護株）
- **w4 (テクノロジー感応度)**: テクノロジー・イノベーションに対する感応度（プラス＝テック関連、マイナス＝非テック）
- **w5 (コモディティ感応度)**: コモディティ価格・原材料価格に対する感応度（プラス＝資源・原材料、マイナス＝加工・消費）
- **w6 (金利感応度)**: 金利変動に対する感応度（プラス＝金利上昇恩恵、マイナス＝金利上昇打撃）
