## 1. Hypothesis

The current `build_weights_minvar` treats `Omega_gap` as a point estimate.
Gap-adjusted covariance estimates contain noise, especially in off-diagonal
(correlation) structure. By modelling an uncertainty set around the covariance
and optimising for the worst case, we can suppress weight concentration
(corner solutions) without adding signal-level parameters.

## 2. Methods

Three robust uncertainty sets are evaluated:

1. **Diagonal inflation**: `Σ_robust = Σ + κ·diag(Σ)` — variance estimation uncertainty
2. **Box uncertainty**: `Σ_robust = Σ + κ·|Σ|` — element-wise worst case (Goldfarb & Iyengar 2003)
3. **Spectral norm ball**: `Σ_robust = Σ + ρ·I` — worst case under `||Δ||₂ ≤ ρ`

All methods modify the covariance before the closed-form MinVar solve:
`(α·Σ_robust + (1-α)·I) w = (1-α)·w_signal`

No convex solver (CVXPY) is required — the closed-form solution is preserved.
