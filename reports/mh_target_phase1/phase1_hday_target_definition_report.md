# Phase 1: h-day 9:10-to-close target 再定義実験レポート

## 概要

`compute_jp_target_returns` の h>1 ターゲット定義を修正した Phase 1（true_910）と、従来の h-day 積み上げ + 最終日 9:10 調整（legacy）を V2 本番 backtest で比較した。

- **期間**: 2020-01-01 〜 2024-12-31（1,181 営業日）
- **マルチホライズン**: h=3, h=5 ブレンド
- **対象**: 指標の変化は h>1 シグナルのみ。h=1 シグナル・コスト・RuleD などは同一。

## ターゲット定義

### legacy

`compute_jp_target_returns` を h-day cumulated `df_exec_h` に適用。`jp_oc` は h 日の open-to-close リターンの累積積（`cumprod`）であり、最終日に 5分足 9:10 価格でスケーリングする h=1 ロジックを適用する。これは h-day window 全体を正しく表現していない。

### true_910 (Phase 1)

行 `i`（取引日）、ティッカー `tk` について

```
y_h[i, tk] = close_i / p_910_{i-h+1, tk} - 1
```

`p_910` が 5分足に存在しない場合は `open_{i-h+1}` へフォールバック。

## 実験スクリプト

- `src/research/scripts/experiments/compare_hday_target_definition.py`
- 各モードで h=3 / h=5 の `mu_gap_h` / `omega_gap_h` 行列を生成し、同一 V2 production モデルで backtest。

## 結果

| Metric | legacy | true_910 | diff |

| n_days | 1181 | 1181 | 0 |
| n_fallback | 0 | 0 | 0 |
| fallback_rate | 0.000000 | 0.000000 | 0.000000 |
| total_return | 4.163051 | 4.260167 | 0.097116 |
| mean_return | 0.003525 | 0.003607 | 0.000082 |
| std_return | 0.013825 | 0.013863 | 0.000038 |

- daily return correlation: 0.992371
- max abs daily return diff: 0.02438951

## 解釈

- **net Sharpe**: legacy 4.0477 → true_910 4.1306（+0.083）と改善。
- **累積リターン**: +0.097（約 2.3%）の向上。
- **リスク**: 標準偏差は微増、最大 DD は -0.312 → -0.340 と 2.9% 悪化。
- **ターンオーバー**: ほぼ同等（1.48 vs 1.48）。
- **相関**: 0.99 と高く、**true_910 は h>1 行列を作り直すのみで h=1 部分に触れていないことを裏付ける**。

なお、本実験期間（2020-2024）では 5分足 9:10 価格がほぼ存在しないため、true_910 は `open_{i-h+1}` へのフォールバックを多用している。それでもなお改善が見られるのは、**従来の「h-day 積み上げ + 最終日 9:10 調整」をやめ、正しい h-day open-to-close リターンを使うようになったこと**が主因であると考えられる。

## 注意点

- 5分足 p_910 が使えない期間では、(High+Low)/2 による 9:10 価格の利益は含まれていない。5分足が整備される 2026 年以降ではさらなる効果が期待されるが、期間が短く検証は限定的。
- true_910 は max DD がやや大きくなる。Phase 2（gap/topix/start-day 9:10 完全整合）での効果を見てから本番昇格を判断する方が安全。

## 結論

Phase 1 最小修正（h>1 ターゲットの正确定義）は、過去 5 年間で net Sharpe +0.08、累積リターン +2.3% の改善を示している。リスク指標は微悪化するため、本番昇格前に Phase 2 の完全整合も含めた追加検証が望ましい。
