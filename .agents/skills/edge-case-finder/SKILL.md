# 境界値・異常系の分析

不変条件はルートの `AGENTS.md` を参照する。以下のパスはリポジトリルート基準。変更箇所と呼び出し元に関係する観点を選び、無関係な全機能の検査を義務化しない。

| 観点 | 確認する条件 |
|---|---|
| ローリング・事前分布 | 窓長の直前/一致/直後、当日混入、履歴不足、2010–2014 の不足、先頭1260行への意図しない代替 |
| PIT・時刻 | quantile 閾値の同値、欠損履歴、当日/未来履歴、公表時刻、JP/US 祝日・DST・年末年始、重複/非単調日付 |
| 欠損・配列 | 空/単一行、NaN/Inf、片側ティッカー不足、列順の入替、設定と行列次元の不一致 |
| 状態・キャッシュ | インスタンス間の共有、別 config / データ版での再利用、不正値の保存、当日ファイル不在・前日ファイルのみ |
| フォールバック | on-demand 成功/無効/入力不足/例外、終端フラット、数値/リーク監査失敗、PIT multiplier、次回正常入力での復帰 |
| ポートフォリオ | 全ゼロ/同値/極端なシグナル、片側空、単一銘柄集中、RuleD 後のモデル制約とレバレッジ後の実効制約 |
| コスト・保有 | 金曜→月曜、連休、最終日、ポジション解消日、ゼロ取引、往復と片道の重複課金 |
| I/O・再試行 | 取得期限、SQLite競合、部分書込み、タイムアウト後の遅延完了・重複注文 |

機能に触れる場合のみ追加する:

- **Copula**: ν最適化の非収束、特異行列、ブレンド重みの端点・ストレス境界、相関の対称性/PSD、推定窓への当日混入。
- **MinVar**: αの端点と関数契約上の等価性、片側1銘柄、特異/ゼロ共分散、long/short 側の正規化。過去の Sharpe 値を境界条件の期待値にしない。
- **Macro / overlay / multi-horizon**: 入力欠損、ゼロ surprise、過大 scale、学習期間や複数 horizon のラベル重複、基準日やファイル日付の不一致。設定キーと期待挙動は現行コードで確認する。

## 成果物

各ケースを「入力条件 / 現行挙動 / 期待挙動 / 実害 / 根拠ファイル・行 / 最小再現またはテスト案」で整理する。発生未確認の仮説は実在する不具合と区別する。

独立した分析依頼では `reports/<作業名>/` に保存する。実装・レビューの一部なら既存のタスクレポートやテストへ統合し、重複レポートを作らない。修正も依頼されていればその範囲で対応し、テスト設計は `test-gen`、時系列監査は `leak-audit` を必要に応じて使う。
